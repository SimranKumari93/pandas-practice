# Data Cleaning with Pandas  

This repository is created to practice and demonstrate **data cleaning techniques using Pandas**. It showcases how raw datasets can be transformed into structured, analysis-ready data.  

## Datasets  
- The very first dataset used here is **Netflix**.  
- More datasets will be added gradually for broader practice and coverage.  

## Tools & Libraries  
- Python, Pandas, Jupyter Notebook  

## Objectives  
- Handle missing values  
- Remove duplicates  
- Fix inconsistent formatting  
- Transform and standardize data  
- Explore real-world datasets
- Dealing with duplicates
- Parsing and cleaning dates
- String operations and text cleaning
- Outlier detection and treatment
- Encoding categorical variables
- Data type conversions
- Data aggregation and transformation
- Merging and joining datasets
- Creating reusable cleaning functions
